###### DESCRIÇÃO

Desenvolva um gerador de QR Codes personalizado para e-commerces utilizando Node.js, executado diretamente no terminal. O projeto utiliza Node.js para facilitar a criação de QR Codes de forma prática e rápida, sem a necessidade de uma interface gráfica, proporcionando uma experiência eficiente para gerar QR Codes de links de produtos, permitindo acesso direto a páginas de vendas online.
